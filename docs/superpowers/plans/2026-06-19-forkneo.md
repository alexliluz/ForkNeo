# ForkNeo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready TypeScript CLI that scans GitHub forks, converts one into an independent repository through a mirror migration, and verifies the result.

**Architecture:** Commander command handlers coordinate injected GitHub and Git service interfaces. Octokit and Execa provide production adapters, while pure utility modules own parsing, naming, comparison, and report formatting for deterministic tests.

**Tech Stack:** Node.js 20+, TypeScript, Commander, Octokit, Execa, Ora, Chalk, Inquirer, Zod, dotenv, fs-extra, Vitest, tsup.

---

## File Map

- `src/index.ts`: executable entry point and exit-code handling.
- `src/cli.ts`: Commander program construction and dependency wiring.
- `src/commands/*.ts`: scan, convert, and verify orchestration.
- `src/github/*.ts`: authentication and Octokit repository operations.
- `src/git/*.ts`: Git mirror and LFS adapters.
- `src/utils/*.ts`: errors, names, temporary directories, output, and reports.
- `src/types/index.ts`: shared service and domain contracts.
- `tests/**/*.test.ts`: behavioral tests mirroring source responsibilities.
